# 마을 전략 (village2)

사내 포털용 실시간 마을 전략 게임. PHP 8 + MySQL/MariaDB, 프레임워크 없음.
전체 설계는 [docs/PLAN.md](docs/PLAN.md) 참고.

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기반: 폴더·DB 자동 생성, SSO 연동, 설정 테이블, 관리자 골격 | ✅ |
| 2 | 마을: 자원 자동 축적, 건설·철거·배치, 격자 확장, 아이소메트릭 화면·카메라 | ✅ |
| 3 | 주민·병종·훈련 대기열·대장간 연구 | ✅ |
| 4 | 육각 맵·이동 | ✅ |
| 5 | 합류·동맹·전투 | |
| 6 | 안개·시야·PvP 안전장치 | |
| 7 | 협동 몬스터 | |

## 설치

1. 이 폴더를 `/volume1/web/portal/village2/` 에 둔다. 포털의 `shared/auth.php` 가 `../shared/auth.php` 위치에 있어야 한다.
2. 같은 폴더에 `config.local.php` 를 만든다 (git 에 올리지 않음).

   ```php
   <?php
   $VG_CONFIG['db_host'] = 'localhost';
   $VG_CONFIG['db_port'] = 3307;              // Synology MariaDB 10 기본 포트
   // $VG_CONFIG['db_socket'] = '/run/mysqld/mysqld10.sock';
   $VG_CONFIG['db_user'] = 'village2';
   $VG_CONFIG['db_pass'] = '********';
   $VG_CONFIG['admins']  = ['포털사용자id또는로그인명'];
   ```

   DB 사용자에게 `village2_db` 를 만들 권한(CREATE)이 있어야 한다. 없으면 DB 만 미리 만들어 두고 그 DB 에 모든 권한을 주면 된다.
3. 브라우저로 `/portal/village2/` 를 열면 첫 접속 때 DB·테이블·기본 설정·건물 정의가 자동으로 만들어지고 내 마을이 생긴다.

관리자 판정: `config.local.php` 의 `admins` 목록, 또는 포털 `getSessionUser()` 결과에 `is_admin`/`admin` 참값이나 `role = admin` 이 있으면 관리자. 관리자는 상단에 `관리자` 링크가 보인다 (`/portal/village2/admin/`).

### 포털 사이드바 히든 링크

포털 사이드바의 TOOLS 섹션 제목을 링크로 감싸면 된다. 겉보기는 그대로 두고 제목 글자를 누를 때만 들어가게 한다.

```html
<a href="/portal/village2/" style="color:inherit;text-decoration:none;cursor:default">TOOLS</a>
```

## 설계 메모

- **정산(lazy settle)**: 자원은 조회·행동 시점에 `last_settle ~ 지금` 을 한 번에 계산한다. 구간 중간에 끝난 공사는 완공 시각까지 먼저 정산하고 레벨을 올린 뒤 이어서 정산하므로, 접속하지 않아도 결과가 같다.
- **원자적 선점**: 모든 변경은 트랜잭션 안에서 `vg_villages`·`vg_resources` 행을 `FOR UPDATE` 로 잠근 뒤 정산 → 행동 순서로 한다. 동시 요청이 와도 차감·생산이 중복되거나 사라지지 않는다 (테스트로 확인).
- **시간 일치**: 공사 시작·완료 시각은 서버가 정해 DB 에 저장하고, 화면은 서버 시계와의 차이를 보정해 같은 시각으로 남은 시간을 그린다. 완료 시각이 지나면 화면이 서버에서 다시 읽는다.
- **크리티컬 생산**: `crit_tick_sec` 주기마다 `crit_chance_pct` 확률로 그 주기 생산량이 `crit_mult` 배. 정산 구간의 주기 수로 이항분포 표본을 뽑아 한 번에 반영한다.
- **제련소**: 철광석을 `smelt_iron_per_gold` 개 써서 금괴 1개. 철광석 재고(+구간 중 광산 생산분)만큼만 제련하고, 바닥나면 들어오는 만큼만 돌아간다.
- **칸**: 회관은 0번(가운데), 일반 칸 1~16 은 안쪽부터 열림, 성벽 같은 둘레 건물은 90번대. 칸 수를 줄여도 이미 건물이 있는 칸은 보호된다.
- **정산 구간**: 건설 완공·연구 완료·훈련 주문 완료 시각마다 구간을 끊어, 각 구간에서 생산 → 식량 유지비(주민+병력) → 주민 근무(경험치·특화) → 훈련 진행 순으로 계산한다.
- **주민**: 고용비 없음, 식량만 소비. 인구 상한 = 회관 레벨 × `villager_cap_per_hall`. 생산 건물에 배치하면 +10% (레벨당 +2%, 같은 종류 건물에서 24시간 일하면 특화 +10%). 마을 화면에서 건물 옆에 주민이 서 있다.
- **일꾼**(민병 대신): 마을회관에서 훈련. 전투력은 낮지만 마을에 있는 일꾼 1명당 새로 시작하는 공사 시간 1% 단축(최대 50%). 4단계부터 맵에서 자원 거점 채집·다리 건설에 쓸 예정.
- **훈련**: 훈련 건물 종류별 대기열이 동시에 돌고, 한 대기열 안은 주문 순서대로. 속도 = 1 + 0.15 × (같은 종류 건물 레벨 합 − 1). 취소 시 남은 수량 50% 환급, 해산은 환급 없음. 식량이 바닥나면 시간당 5% 병력 이탈.
- **연구**: 대장간 레벨에 따라 열림. 훈련 속도는 즉시, 공격·방어·운반은 5단계, 행군 속도는 4단계부터 적용.
- **세계 맵**: 축좌표 (q, r) 육각 타일. 시드로 높이·습도 노이즈를 만들어 평원·숲·산·호수를 정하고, 산에서 낮은 쪽으로 강을 흘린 뒤
  광산·농장 거점과 항구를 놓는다. 마을은 서로 `village_min_distance` 이상 떨어진 평원에 자동 배치. 관리자 지형·맵 탭에서 칠하기·마을 옮기기·재생성.
- **부대 이동**: 서버는 `path_json`(타일마다 출발 기준 도착 초)과 `depart_at` 만 저장하고 위치는 경과 시간으로 계산한다. 이동 속도는
  가장 느린 병종 × 지형 이동 비용, 회군은 70% 속도. 이동 중 경로를 바꾸면 가던 칸까지는 마저 간다. 도착·다리 완성은 마을 정산(또는 맵 조회) 때 처리.
  경로 미리보기는 브라우저에서 같은 규칙의 A* 로 바로 계산하고, 출진·이동 때 서버가 다시 계산한다.
- **일꾼의 맵 활용**: 광산·농장 거점·항구·숲에 주둔한 부대의 일꾼이 자원을 모아(운반량까지) 마을로 돌아오면 창고에 넣는다.
  일꾼 5명 이상이면 바로 옆 강에 다리를 놓을 수 있다(나무 300, 10분).
- **그림**: 이미지 업로드 없이 `assets/js/art.js` 가 SVG 로 직접 그린다. 건물은 레벨 3단계(Lv1~3 / 4~7 / 8+)로 모양이 바뀌고,
  관리자가 새로 추가한 건물은 분류별 기본 집 모양. 관리자 `그림` 탭에서 전체 그림을 한눈에 볼 수 있다.
- **설정**: 게임 수치는 전부 `vg_settings` / `vg_building_defs` 에 있고 관리자에서 바꾼다. 새 설정을 코드에 추가하면 `VG_DEFAULTS_VERSION` 을 올린다 (기존 값은 보존, 새 키만 추가). 스키마 변경은 `vg_migrations()` 에 새 번호로만 추가한다.

## 테스트

로컬 MySQL/MariaDB 에 `test` 가 들어간 이름의 DB 를 지정해 실행한다. 그 DB 는 지우고 다시 만든다.

```sh
VG_DB=village2_test php tests/run.php
```

정산 수치, 완공 시각 반영, 창고 한도, 건설 규칙(칸·회관 레벨·동시 공사·상한), 취소·철거 환급, 이동·맞바꾸기, 제련소 재고 제한, 크리티컬,
주민(상한·배치 보너스·레벨·특화), 맵 생성(시드 재현·마을 간격), 길찾기(강·호수·남의 마을·지형 비용), 부대(편성·속도·경로 변경·주둔·회군·귀환·부대 수 제한),
채집·다리, 훈련(순서·동시 진행·속도·취소 환급·대기열 제한·건물 없을 때 멈춤), 유지비·굶주림 이탈, 일꾼 건설 단축, 연구, 동시 요청 정산·지불을 검사한다.

## 4단계 동작 확인 체크리스트

- [ ] 세계 맵 탭에 육각 맵이 보이고 휠(커서 기준)·드래그·핀치·+/−/전체/마을 버튼이 된다. 드래그 뒤에는 클릭이 눌리지 않는다
- [ ] 새 부대 편성 → 병종·수량 선택 → 지도에서 목적지를 누르면 경로와 도착 예정 시간이 바로 보이고, 출진하면 그 시간에 도착한다
- [ ] 강·호수·남의 마을은 지나가지 않고 돌아간다. 산·숲은 느리다
- [ ] 이동 중 다른 곳을 누르고 이동하면 경로가 바뀐다. 회군은 더 느리다. 마을에 도착하면 병력이 마을로 돌아온다
- [ ] 일꾼이 있는 부대를 광산·농장 거점·항구·숲에 주둔시켜 채집하면 짐이 쌓이고, 마을로 돌아오면 창고에 들어간다
- [ ] 일꾼 5명 이상 부대를 강 옆에 주둔시켜 다리를 놓으면, 완성 후 그 강을 건너는 길이 생긴다
- [ ] 부대에 나가 있는 병력도 마을 식량을 먹는다 (병력 탭에 출진한 부대 표시)
- [ ] 관리자: 지형·맵 탭에서 지형/거점 칠하기, 마을 옮기기, 시드로 재생성, 지형 값 편집. 부대 탭에서 모든 부대 보기·즉시 귀환

## 3단계 동작 확인 체크리스트

- [ ] 상단에 `인구 N/상한` 이 보이고, 주민 탭에서 주민 받기·배치·쉬게 하기·내보내기가 된다
- [ ] 생산 건물에 주민을 배치하면 그 건물 생산량이 오르고, 마을 화면 건물 옆에 주민이 보인다
- [ ] 주민이 일한 시간에 따라 레벨이 오르고, 같은 종류 건물에서 24시간 일하면 특화된다
- [ ] 병력 탭: 훈련 건물 종류별로 대기열이 따로 동시에 진행되고, 남은 시간이 실제 완료 시각과 맞는다
- [ ] 같은 종류 훈련 건물을 더 짓거나 레벨을 올리면 훈련이 빨라진다 (속도 ×표시)
- [ ] 병종 카드에 상성(강함/약함)이 표시되고, 건물 레벨이 모자라면 잠겨 있다
- [ ] 훈련 취소(남은 수량 50% 환급), 해산(환급 없음)이 된다
- [ ] 일꾼을 훈련하면 새로 시작하는 공사 시간이 줄어든다
- [ ] 병력·주민이 식량을 먹어 식량 순생산이 줄어든다 (0 아래로 가면 병력이 떠난다)
- [ ] 연구 탭: 대장간 레벨에 따라 연구가 열리고, 한 번에 1개씩 진행된다
- [ ] 관리자: 병종 탭·연구 탭 편집, 건물 탭의 '훈련 병종' 체크(병종 탭과 양방향), 플레이어 탭에서 병력 수·연구 레벨 변경

## 2단계 동작 확인 체크리스트

- [ ] 첫 접속 시 DB 가 만들어지고 회관 Lv1 + 농장 + 벌목장이 있는 마을이 보인다
- [ ] 상단 자원 5종이 이름과 함께 표시되고, 초당 생산량만큼 숫자가 올라간다
- [ ] 빈 칸(+) 을 눌러 건물을 짓고, 말풍선 안 진행 막대와 남은 시간이 표시된다. 시간이 끝나면 바로 완공된다
- [ ] 여러 건물을 동시에 지을 수 있고 `동시 건설 수` 를 넘으면 막힌다
- [ ] 건물 위에 `이름 Lv` 과 `생산물 +N/s` 이 글자로 보이고 옆 타일 이름표와 겹치지 않는다
- [ ] 회관 레벨을 올리면 칸이 늘어나고, 다른 건물은 회관 + 2 레벨까지만 오른다
- [ ] 건물 이동(빈 칸)·맞바꾸기, 철거(일부 환급), 공사 취소(환급)가 된다
- [ ] 성벽 버튼으로 성벽을 지으면 마을 둘레에 뒤/앞 성벽이 그려진다
- [ ] 휠 줌(커서 기준)·드래그·핀치·+/−/맞춤이 되고, 드래그 후에는 클릭이 눌리지 않는다
- [ ] 관리자: 설정 검색·저장, 격자 확장 미리보기, 건물 정의 편집, 그림 탭(건물·성벽·병종 전체 보기), 플레이어 건물 레벨·자원 직접 변경, 초기화
