# 마을 전략 게임 신규 구축 계획서 (village2)

> Claude Code 구현용. **기존 코드·DB는 없는 상태에서 처음부터 만든다.**
> **그림 원칙(변경)**: 건물·성벽·병종·부대·몬스터 그림은 이미지 업로드 없이 전부 코드(`assets/js/art.js`, SVG)로 그린다.
> 아래 설계 수치는 이전 버전에서 조정해 온 값을 **초기 기본값**으로 가져온 것이며, 전부 관리자 설정으로 바꿀 수 있게 만든다.

---

## 1. 개요

- **컨셉**: 사내 유저끼리 즐기는 실시간 마을 전략 게임. 자원 채집·건설로 성장하고, 육각 타일 세계 맵에서 부대를 움직여 싸우고 협력한다.
- **환경**: 포털 통합 (PHP/MySQL), 포털 SSO(`shared/auth.php`의 `getSessionUser()`) 연동, 사내 유저 대상
- **경로/DB**: `/volume1/web/portal/village2/`, DB `village2_db` (첫 실행 시 스키마 자동 생성)
- **진입**: 포털 사이드바 TOOLS 섹션 제목의 히든 링크
- **전투 참고**: 모바일 게임 '삼국지 천하결전' (구체 규칙은 미확인, 좋았던 점을 추후 전달받아 반영)

## 2. 확정된 핵심 규칙

- 세계 맵은 **육각 타일**, 이동은 **실시간** (타일당 소요 시간)
- 병력 **분할 발송 없음** → 마을에서 **부대 단위로 편성**해 출진
- 부대는 평원 등에 **대기(주둔)** 가능, 언제든 재이동·회군
- **합류는 누구나 가능**, 대장이 수락 (가정)
- **평원에서는 인접한 비동맹 부대와 전투 가능** (숲·산은 같은 타일 진입 시에만 전투, 가정)
- 사내 PvP는 과열 방지 장치 필요 (시즌·보호막·약탈 상한, 7장)

## 3. 마을 (건설·자원·주민)

### 3-1. 자원 5종
돈, 식량, 나무, 철광석, 금괴. 상단 자원 표시는 **색 아이콘만이 아니라 글자로 이름 표기**.

### 3-2. 건물
- **마을회관**: 다른 건물 상한 = 회관 레벨 + `hall_headroom`(기본 2). 회관 레벨에 따라 타일 확장
- **생산 건물**: 농장·벌목장·광산·제련소(철광석→금괴, **철광석 재고만큼만 제련**) 등. `multi` 플래그로 여러 채 건설 가능
- **병영·궁사양성소·공성작업장·마굿간**: 병종별 훈련 건물 (아래 3-4)
- **대장간**: 무기단조·갑옷제작 등 연구
- **망루**: 시야 반경 및 정찰 범위 증가
- **성벽**: 칸을 쓰지 않는 **둘레 건물** (slot 90번대 예약). 뒤 성벽/앞 성벽을 나눠 그림 (레벨 3단계: 목책 / 석벽 / 높은 석벽·원탑·성문)
- 건물 그림은 레벨 3단계 (Lv1~3 / 4~7 / 8+)
- **건설은 동시 진행** (순차 대기열 아님). 표시 시간과 실제 시간이 일치해야 함
- **철거** 시 자재 일부 환급, **배치 변경(이동·맞바꿈)** 지원
- 마을 격자: 시작 `cells_base` 4칸, 회관 레벨당 `cells_per_hall_level` 2칸, 최대 16칸. 기존 건물이 있는 칸은 보호

### 3-3. 생산 시스템
- 자원은 시간 경과에 따라 자동 축적 (접속하지 않아도 조회 시점에 정산)
- 초반 벌이 속도는 빠르게 (느리다는 피드백 반영)
- **크리티컬 생산**: 확률·배수·건물별 초당 생산량을 관리자에서 조정
- 건물 위에 **생산물 이름 + 숫자**를 글자로 표시. 이름표가 옆 타일에 걸치지 않게 배치

### 3-4. 병종 (건물별 분리, 건물 레벨로 해금)
| 훈련 건물 | 병종 |
|---|---|
| 병영 | 민병, 창병, 검사, 근위기사 |
| 궁사양성소 | 궁수 |
| 공성작업장 | 공성추, 투석기 |
| 마굿간 | 기병, 코끼리병 |

- 훈련 대기열은 **건물별로 분리(동시 진행)**. 건물 개수·레벨 합에 비례해 속도 증가(`barracks_speed_per_level` 기본 0.15)
- 훈련 중 **취소**(남은 수량 자원 `train_cancel_refund_pct` 50% 회수), 보유 병력 **해산**(회수 없음, 유지비만 감소)
- 병종 상성: 창▶기병▶궁수▶창 삼각, 검사▶민병·공성추 (`counters_on`, 상대 부대 구성 가중평균 배수). 훈련 화면에 상성 표시
- 병력 유지비: 식량

### 3-5. 주민
- 식량만 소비 (고용비 없음, 유지비 `villager_food_each`)
- **인구 상한 = 회관 레벨 × `villager_cap_per_hall`** (기본 1). 화면에 `인구 N/상한` 표시
- 생산 건물에 배치하면 보조 보너스 (기본 10% + 레벨당 2% + 특화 10%, 약하게)
- 놀고 있는/일하는 주민 구분, 레벨업, 같은 일을 `villager_spec_hours`(24h) 하면 자동 특화
- 주민 탭: 고용·해고·배치

## 4. 세계 맵 (육각 타일)

- 좌표: 축좌표 `(q, r)`. 지형: 평원, 숲, 산, 강, 호수 (바다는 선택)
- 마을과 자원 거점(광산·농장·항구)도 타일에 배치
- 지형별 이동 비용·방어 보너스·통행 가능 여부는 관리자에서 편집
  - 예: 평원 1, 숲 2, 산 3, 강은 다리 없으면 불가 / 산 방어 보너스 큼, 평원은 기병 유리
- 맵 생성: **시드 기반 자동 생성 + 관리자 수동 편집**, 마을 시작 위치는 서로 너무 가깝지 않게 배치
- **안개(시야)**: 부대·마을·망루 주변 반경만 표시. 안개 밖 부대는 미표시
- 렌더링: Canvas, **보이는 영역만 그리기**. 휠 줌·드래그·핀치·+/−/맞춤 버튼, 줌 중심은 커서 기준 유지, 드래그 후 클릭 무시

## 5. 부대·이동·합류

### 5-1. 부대 편성
- 마을의 부대 편성 화면에서 병종·수량을 골라 **부대 하나**를 만들어 출진 (수량 쪼개기 발송 없음)

### 5-2. 이동
- 목적지 클릭 → A\* 경로 미리보기 + 예상 도착 시간 (서버가 재검증)
- **서버는 `path_json`과 출발 시각만 저장**, 현재 위치는 경과 시간으로 계산
- 부대 속도 = 구성 병종 중 **가장 느린 병종**
- 이동 중 경로 변경·회군 가능. 회군은 진군보다 느리게(`march_return_speed_pct` 기본 70)
- 도착 후 **주둔** 상태 유지, 주둔 중에도 식량 유지비 발생 (무한 대기 방지)

### 5-3. 합류·연합 부대
- 같은 타일 부대끼리 합류 신청 → 대장 수락 → 하나의 대열로 이동
- 병력 **소유권은 개별 유지**. 대장만 이동·공격 명령
- 이탈 시 소유 병력만 분리되어 그 타일에 단독 주둔
- 전투 손실은 각자 비율대로, 전리품·생존 병력은 **기여도(투입 전투력) 비례 분배**

### 5-4. 동맹
- 동맹 생성·가입·탈퇴. 동맹끼리는 전투 불가
- 동맹 아닌 부대와도 합류는 가능 (대열 내부에서는 서로 공격 불가)

## 6. 전투

- **트리거**: (a) 적 부대·마을 타일 진입, (b) 평원 인접 공격 명령
- **계산**: 병종 상성 + 지형 방어 보너스 + 방어측 홈 보너스
  - `def_home_bonus_pct` 기본 25, `def_base_power` 기본 30 (설정화)
  - 공격 실패 시 생존 공격군 **패주 손실** `atk_rout_pct` 기본 60 (수비가 불리하지 않도록)
  - 라운드 방식, 패주는 라운드 수에 미포함
- 원거리(궁수·투석기)는 인접 타일 지원사격 (2단계 이후 확장)
- **전투 보고서**: '공격측 → 방어측 침공', '○○ 승리', 라운드별 결과, 패주 행, 참전 소유자별 손실, 지형 표시
- **동시성**: 정산 함수는 **원자적 선점(락)** 필수. 중복 정산으로 병력이 늘어나는 버그 방지 (조회 시점 lazy resolve + 트랜잭션)

## 7. 경쟁·PvP 안전장치

- **시즌제**: 4~8주 단위로 순위 정산, 마을 리셋 또는 일부 이월
- **신규 보호막**: 가입 후 N시간 마을 공격 불가, 미접속 유저 보호
- **약탈 상한**: 한 번에 빼앗기는 자원 상한
- **점령 거점**: 공용 거점(광산·항구)을 두고 다투는 목표형 싸움
- (선택) 부서·팀 대항 순위

## 8. 협동 PvE (공공의 적)

- 몬스터가 **전체 서버에 등장**, 특정 마을 지명 없음
- 참여는 **부대 파병 방식**, 평원에 모여서 함께 막는 구조
- 제한시간 내 못 막으면 **각 마을이 자기 마을 규모에 비례해 피해** (전원 페널티)
- 성공 시 참여자 전원에게 동일한 자원 보상
- **보상 클레임 시스템**: 창고 용량이 부족해 못 받은 보상은 기록해 두었다가 나중에 수령
- 이벤트 생성은 관리자 메뉴 버튼, 몬스터 그림도 코드로 그림

## 9. 관리자 페이지

탭 구성 (기본): 요약 / 설정 / 건물 / 병종 / 연구 / 지형·맵 / 그림 / 플레이어 / 부대·전투기록 / 이벤트(몬스터) / 초기화

- **설정 탭**: 종류별 묶음(접기) + 이름·설명 검색창. 격자 확장 전용 카드(`grid_expand_levels` 편집 + 미리보기)
- **그림**: 코드로 그린 건물(3단계)·성벽·병종 전체 미리보기 (업로드 없음)
- **병종**: 병종↔훈련 건물 연결을 **양방향 편집**
- **플레이어 탭**: 건물 레벨·병력 숫자·대장간 연구 레벨 **직접 변경**. 세로로 길어지지 않게 미니줄 가로 격자 + 접기(details)
- **맵 탭**: 지형 편집, 시드 재생성, 시작 위치 배치
- 제련소 카드: 철광석 순감소 시 경고 표시

## 10. 화면 · 디자인

- 마을: **아이소메트릭** 그림, 양피지 톤 UI. 건물 간 간격을 충분히 두고 확대·축소·이동 카메라 제공
- 공사 진행 막대는 **말풍선 안**에 표시
- 세계 맵: 육각 타일, 안개, 부대 아이콘과 이동 경로 표시
- 전투 화면: 초기에는 **보고서 중심**, 이후 지도 위 부대 충돌 연출 추가

## 11. 데이터 모델 (요약)

- 마을: `vg_villages`, `vg_buildings`, `vg_villagers`, `vg_resources`
- 정의: `vg_building_defs`, `vg_unit_defs`(`train_bld` 포함), `vg_research_defs`, `vg_terrain_defs`, `vg_settings`
- 맵: `vg_map_tiles(q, r, terrain, owner_village_id, feature)`
- 부대: `vg_armies(id, owner_id, leader_id, q, r, state, path_json, depart_at, ...)`, `vg_army_units(army_id, owner_id, unit_type, count)`
- 합류·동맹: `vg_join_requests`, `vg_alliances`, `vg_alliance_members`
- 전투·이벤트: `vg_battles`, `vg_battle_reports`, `vg_monster_events`, `vg_reward_claims`
- 훈련: `vg_train_queue`(건물별)

## 12. 구현 단계

각 단계 끝에 동작 확인 후 다음으로 진행.

1. **기반**: 폴더·DB 자동 생성, SSO 연동, 설정 테이블, 관리자 골격
2. **마을**: 마을 생성, 자원 자동 축적, 건물 건설·철거·배치, 격자 확장, 아이소메트릭 화면·카메라
3. **주민·병종**: 주민 시스템, 병종 정의, 훈련 건물별 대기열, 훈련 취소·해산, 대장간 연구
4. **육각 맵·이동**: 맵 생성, 타일 렌더링, A\*, 실시간 위치 계산, 부대 편성·출진·대기·회군
5. **합류·동맹·전투**: 합류/이탈, 소유권 추적, 동맹, 타일 진입 전투, 평원 인접 공격, 지형 보너스, 전투 보고서
6. **안개·시야·PvP 안전장치**: 안개, 망루 연동, 시즌·보호막·약탈 상한
7. **협동 몬스터**: 이벤트 생성, 평원 집결 방어, 보상 클레임

## 13. 주의 사항

- 이동 중 부대가 많아도 부하가 없도록 **저장은 경로+시각, 위치는 계산**
- 대기 부대 공격·합류 신청이 겹치는 경합은 **트랜잭션으로 순서 보장**
- 건설·훈련 시간은 화면 표시와 실제가 항상 일치해야 함
- 관리자 설정 값은 하드코딩 금지, 모두 `vg_settings`로 관리
- 성능: 주민·생산 tick은 prepare 재사용, 변화 없는 항목은 스킵
